| 기능 구분            | 입력 동작 예시                                   | 출력/결과 동작                                   | 예외/경계 조건                                   |

## 2) Python 구현 시 주의점

- 외부 제공 Tuner 모듈은 직접 구현하지 않고 **Mock(Fake 포함)** 으로 대체한다.
- 가상환경(venv)에서 의존성 관리 및 테스트 실행을 보장한다.
- `pytest` + `pytest-cov` 기반으로 테스트를 작성하고, `coverage.py`로 커버리지 측정한다.
- Controller 모듈은 TDD 방식으로 점진적 구현 및 리팩토링을 수행한다.
- Python 3 문법 준수, type hint 적극 활용, 데이터 구조는 `dataclass`로 표현 가능.

## 3) 예외/경계값 조건

- 버튼 종류: 숫자(0~9), 채널 업/다운, 확인, 채널검색, 선호채널추가, 다음선호채널
- 채널 범위: 0 ~ 99
- 경계 조건:
  - 0번 채널에서 다운 → 99번 채널
  - 99번 채널에서 업 → 0번 채널
  - 선호 채널 목록이 비어있을 때 다음 선호 채널 버튼 → 무효 처리
  - 숫자 입력 중 다른 버튼 입력 시 마지막 숫자 무효화
  - 채널 검색 결과가 없을 때 업/다운 → 단순 ±1 이동

## 4) pytest 기준 테스트 시나리오 목록

1. 숫자 버튼 입력 후 `확인`으로 채널 변경  
   - 입력: `1` + `확인` → 출력: 1번 채널  
   - 입력: `1` + `2` + `확인` → 출력: 12번 채널  
   - 경계: `0` + `7` → 출력: 7번 채널  

2. 숫자 입력 중 다른 버튼 입력 시 마지막 숫자 무효화  
   - 입력: `4` + `5` + `6` + `업` → 출력: 45번 채널, 6 무효  

3. 선호 채널 추가/삭제 동작  
   - 입력: 현재 채널 12, `선호채널추가` → 출력: 목록에 12 추가  
   - 입력: 현재 채널 12, 다시 `선호채널추가` → 출력: 목록에서 12 삭제  

4. 다음 선호 채널 이동 (순환 포함)  
   - 목록: [1, 4, 12, 56], 현재 채널 6, `다음선호채널` → 출력: 12  
   - 목록: [1, 4, 12, 56], 현재 채널 56, `다음선호채널` → 출력: 1  

5. 채널 검색 버튼 동작  
   - 입력: `채널검색` → 출력: 모든 채널 저장(Mock Tuner 활용)  

6. 업/다운 버튼 동작 (검색 결과 없음, 경계값 포함)  
   - 현재 채널 6, `업` → 출력: 7  
   - 현재 채널 99, `업` → 출력: 0  
   - 현재 채널 0, `다운` → 출력: 99  

7. 업/다운 버튼 동작 (검색 결과 있음)  
   - 목록: [4, 6, 14], 현재 채널 6, `업` → 출력: 14  
   - 목록: [4, 6, 14], 현재 채널 15, `다운` → 출력: 14  

8. Mock Tuner 동작 검증  
   - `seek_ch`, `set_ch`, `get_current_ch` 호출 시 Mock이 정상 동작하는지 확인  

9. 예외/경계값 테스트  
   - 채널 범위 초과 입력 (예: 100) → 무효 처리  
   - 빈 선호 목록에서 `다음선호채널` → 무효 처리  
   - 검색 결과 없음 상태에서 업/다운 → 단순 ±1 이동
